# PDF Library

An add-on to store and read PDF documents inside Home Assistant.

## Installation

Add the repository `https://github.com/fenyag7/ha-addons` to the Home Assistant
add-on store, then install **PDF Library**. Supervisor builds the image locally,
so the first install takes a few minutes.

See [DOCS.md](DOCS.md) for options and folder layout.
