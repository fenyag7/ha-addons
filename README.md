# fenyag7 add-ons

Home Assistant add-on repository.

## Installation

Settings → Add-ons → Add-on store → ⋮ → Repositories, then add:

```
https://github.com/fenyag7/ha-addons
```

## Add-ons

- **[PDF Library](pdf_library)** — store and read PDF documents inside Home Assistant.
